Instructor Implementation Guide

Purpose

The Analyst Challenge turns model-checking into a recurring professional routine. Students practice the management science habit of moving from formulation and computation to defensible managerial judgment. The AI-generated report frame is useful because it gives students a realistic reason to verify outputs without making the assignment primarily about technology.

Recommended Semester Use

Course AreaAudit FocusTypical Error Types
Linear ProgrammingFormulation, Solver solution, binding constraints, slackWrong objective, missing constraint, incorrect recommendation from sensitivity result

Integer / Binary ModelsIndivisible decisions, logical constraints, feasibilityRounding an LP solution, violating either-or constraints

Forecasting / Inventory / QueuingAssumptions, service levels, capacity implicationsUsing the wrong demand measure, ignoring variability, overclaiming precision

Setup Steps

  1. Publish the overview page in Canvas before the first audit.
  2. Create one Canvas assignment per audit using the reusable assignment template.
  3. Attach or link the relevant executive report, data file, spreadsheet, or model prompt.
  4. Attach the student templates or link to the GitHub Pages package.
  5. Add the grading rubric to Canvas as a rubric or paste the point rows into the assignment description.

Instructor Notes

  • Keep the workflow identical across audits so students spend their effort on analysis rather than decoding directions.
  • Design at least one error that is computational and one error that is interpretive.
  • Reward students for identifying when a mathematically correct model is still a poor decision basis.
  • Ask for one paragraph in the executive brief to prevent spreadsheet dumping and encourage managerial synthesis.
  • Use the confidence statement to normalize uncertainty as a professional behavior rather than a weakness.

Fast Launch Plan

  1. Upload or publish this folder with GitHub Pages.
  2. Paste the overview HTML into a Canvas page named The Analyst Challenge.
  3. Create the first assignment from the assignment template.
  4. Link students to the package index page for templates.
  5. Use the rubric at 100 points for the first full audit, or scale it down for a shorter weekly activity.
