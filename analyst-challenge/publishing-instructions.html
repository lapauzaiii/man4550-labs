GitHub Pages and Canvas Instructions

Publish on GitHub Pages

  1. Open the GitHub repository that hosts the MAN4550 course pages.
  2. Upload or commit the full analyst-challenge folder into the repository root.
  3. Confirm the repository also contains the existing root index.html.
  4. In GitHub, go to Settings, then Pages.
  5. Under Build and deployment, choose Deploy from a branch.
  6. Select the branch used for the course site, usually main, and the folder /root.
  7. Save. Wait a few minutes for GitHub Pages to deploy.
  8. Open the published page at https://lapauzaiii.github.io/man4550-labs/analyst-challenge/.

Link from Canvas

  1. Create a Canvas page named The Analyst Challenge.
  2. Switch to the HTML editor.
  3. Paste the contents of canvas/canvas-overview.html.
  4. Add a button or link to the public package page: https://lapauzaiii.github.io/man4550-labs/analyst-challenge/.
  5. Publish the Canvas page.

Create Each Canvas Assignment

  1. Create a new Canvas assignment for the specific audit.
  2. Switch to the HTML editor.
  3. Paste the contents of canvas/canvas-assignment-template.html.
  4. Replace the bracketed placeholders with the audit number, topic, division, due date, and specific report/data links.
  5. Add the rubric rows from instructor/grading-rubric.html.
  6. Publish the assignment and verify that student links open correctly.
