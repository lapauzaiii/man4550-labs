# The Analyst Challenge: AI Decision Model Audits

Publish-ready asset package for MAN4550: Introduction to Management Science.

## Files

- `index.html`: GitHub Pages landing page for the package.
- `canvas/canvas-overview.html`: Canvas-safe overview page HTML.
- `canvas/canvas-assignment-template.html`: Reusable Canvas assignment HTML.
- `templates/cover-sheet.html`: Consulting-style cover sheet, print/PDF-ready.
- `templates/student-executive-brief-template.html`: Student executive brief template.
- `templates/audit-findings-template.html`: Audit findings template.
- `templates/confidence-statement-template.html`: Confidence statement template.
- `templates/ai-disclosure-template.html`: AI disclosure template.
- `instructor/grading-rubric.html`: 100-point grading rubric.
- `instructor/instructor-implementation-guide.html`: Instructor setup and use guide.
- `publishing-instructions.html`: Step-by-step GitHub Pages and Canvas directions.
