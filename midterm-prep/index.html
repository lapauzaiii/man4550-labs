How the midterm is built

The midterm covers Weeks 1–6 only — break-even through integer programming. Regression is not on it. It is 200 points, proctored in Honorlock, and organized around three Cowford cases you already know. Within each case, questions climb from definitions to calculations to diagnosing errors to making a recommendation Damar Okoye would accept.
